# Barotrauma Pterodactyl Eggs 🛥️🌊

Этот репозиторий содержит `egg` файлы для панели управления **Pterodactyl**, предназначенные для быстрого и удобного развертывания серверов игры **Barotrauma**. 

В репозитории представлены два варианта конфигурации, чтобы вы могли выбрать наиболее подходящий для ваших нужд.

---

## 📦 Доступные файлы (Eggs)

### 1. `egg-barotrauma-simple.json` (✅ Рекомендуется к использованию)
Модифицированный и улучшенный egg-файл. 
* **Особенность:** Все переменные и настройки сервера в панели Pterodactyl полностью **переведены на русский язык**. 
* Идеально подходит для быстрого старта и комфортной настройки сервера без необходимости переводить параметры вручную.

### 2. `egg-barotrauma-mod-manager.json`
Стандартный egg-файл с заявленной поддержкой менеджера модов.

> ⚠️ **ПРЕДУПРЕЖДЕНИЕ:** На данный момент этот egg-файл **работает нестабильно** и может вызывать ошибки при запуске или работе сервера. Используйте его на свой страх и риск. Для стабильной работы настоятельно рекомендуется использовать `egg-barotrauma-simple.json`.

---

## ⚙️ Установка

1. Скачайте нужный вам `.json` файл из этого репозитория.
2. Перейдите в административную часть вашей панели Pterodactyl (`Admin Control Panel`).
3. Перейдите в раздел **Nests** (Гнезда) и выберите подходящее гнездо (например, создайте новое гнездо `Barotrauma` или используйте `SteamCMD`).
4. Нажмите кнопку **Import Egg** (Импортировать Egg).
5. Загрузите скачанный `.json` файл.
6. Теперь вы можете создать новый сервер, используя импортированный egg!
